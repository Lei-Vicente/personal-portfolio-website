## 🌟 Key Features & Architectural Highlights

- **Dynamic Island Floating Navigation**: Theme-aware glass navigation bar featuring a physics-accurate gliding capsule indicator, smooth multi-tab transitions, and a one-tap mobile menu with backdrop blur.
- **Interactive Live App Showcases**: Seamless desktop browser mockup previews loaded dynamically for flagship projects with instant static poster fallbacks to eliminate cold-start lag.
- **Persistent Light / Dark Modes**: Strict zero flash-of-unstyled-content (FOUC) theme manager with persistent local preference.
- **Engineered Typography**: Primary sans typography powered by `Plus Jakarta Sans` for clean, professional geometric curves, paired with `JetBrains Mono` for developer metadata.
- **Production-Ready & Responsive**: Fluid responsive layout designed for high-resolution desktop viewports (`max-w-[min(94vw, 1800px)]`) down to mobile screens.
- **Recruiter & ATS Optimized**: Verifiable work experience, linked public resume PDF, LinkedIn integration, and transparent full-stack contribution framing.

## 💻 Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [pnpm](https://pnpm.io/) (`corepack enable pnpm` or `npm install -g pnpm`)

### Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Lei-Vicente/personal-portfolio-website.git
   cd personal-portfolio-website
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Start the local development server**:
   ```bash
   pnpm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   pnpm run build
   ```
   Generates optimized static assets in the `dist/` directory.
